# 🇱🇰 Serendib AI  
### *Your Intelligent Sri Lanka Travel Companion*

Serendib AI is a smart tourism assistant designed to help travelers discover the beauty, culture, and hidden gems of Sri Lanka through an interactive AI-powered chat experience.

Whether you are planning a relaxing beach vacation, scenic hill-country getaway, cultural heritage tour, or food adventure, **Serendib AI** provides instant travel guidance in a simple and elegant interface.

---

## ✨ Why “Serendib”?

**Serendib** is one of the ancient names used for Sri Lanka, symbolizing discovery, wonder, and unexpected beauty — making it the perfect identity for an intelligent travel assistant.

---

## 🌍 What Serendib AI Can Do

### 🏖️ Travel Recommendations
Get personalized suggestions for:

- Beaches  
- Mountains  
- Waterfalls  
- Wildlife parks  
- Historical sites  
- Hidden destinations  

### 🗺️ Trip Planning
Ask for:

Ask natural questions like:

Powered by modern language models for quick and helpful answers.

## 🚀 Run This Project Locally

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/serendib-ai.git
cd serendib-ai
```

---

### 2️⃣ Install Required Packages

```bash
pip install -r requirements.txt
```

---

### 3️⃣ Add Your API Key

Create a file named:

```text
.env
```

Then add:

```text
GROQ_API_KEY=your_api_key_here
```

---

### 4️⃣ Launch the App

```bash
streamlit run app.py
```

Your browser will open automatically.
